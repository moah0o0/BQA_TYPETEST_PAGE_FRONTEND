# 퀴어 활동 캐해 — 프론트엔드

부산퀴어행동 부스 프로그램 **퀴어 활동 캐해**의 웹페이지입니다.
참여자가 QR을 찍어 닉네임 → 15문항 → 한마디를 입력하면, 8가지 유형 중 하나와 해설지를 보여 주고
온라인 행진 대열에 자기 캐릭터와 말풍선으로 합류합니다.

빌드 과정 없는 정적 사이트(HTML/CSS/JS)라 GitHub Pages에 그대로 올리면 됩니다.

## 화면

| 주소 | 내용 |
|---|---|
| `#/` | 첫 화면 (참여 인원, 참여하기, 최근 행진) |
| `#/test` | 닉네임 → 15문항 → 한마디 → 저장 |
| `#/result` | 내 해설지 (쿠키에 저장된 내 결과) |
| `#/result/42` | 42번 결과 해설지 (공유 링크) |
| `#/type/FPM` | 유형 해설 보기 |
| `#/parade` | 행진 대열 (내 캐릭터는 '나' 표시) |
| `#/stats` | 유형별 분포 · 축별 성향 그래프 |
| `label.html` | **운영용** 참여 번호로 Niimbot B1 라벨(50×90mm) 앞·뒤 2장 출력 (블루투스) |
| `admin.html` | **운영용** 번호로 해설지 불러와 영수증 출력 / PNG·텍스트 저장 / 부적절한 한마디 숨기기 |

## 파일 구조

```
index.html            참여자 화면
admin.html            운영용 해설지 출력 화면 (관리자 토큰 필요)
js/config.js          ★ 백엔드 주소 설정
js/content.js         ★ 문항 · 유형 이름 · 해설지 문구 (여기만 고치면 내용 수정)
js/characters.js      캐릭터 표시 (그림이 없으면 임시 캐릭터)
js/api.js             백엔드 통신 (주소가 비면 체험 모드)
js/app.js             화면 로직
js/receipt.js         영수증 해설지 (HTML · 텍스트)
js/admin.js           운영 화면 로직
css/                  스타일
assets/characters/    ★ 유형별 캐릭터 그림 넣는 곳 (README 참고)
```

## 배포 (GitHub Pages)

1. `js/config.js`의 `API_BASE`에 백엔드 주소를 적습니다. 예) `"https://typetest-api.bapc.kr"`
2. GitHub 저장소 **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: `main` / `/ (root)`
3. 커스텀 도메인: `https://typetest.busanqueeract.kr` (저장소의 `CNAME` 파일로 고정)
   커스텀 도메인을 쓰면 Pages 설정에서 도메인을 넣고 DNS에 CNAME을 추가하세요.
4. 백엔드의 `CORS_ORIGINS`에 이 주소의 **origin**(예: `https://moah0o0.github.io`)을 꼭 넣어 주세요.

`API_BASE`가 비어 있으면 **체험 모드**로 동작합니다. 결과가 그 브라우저(localStorage)에만 저장되어
백엔드 없이도 화면을 미리 볼 수 있어요.

## 로컬에서 보기

```bash
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다.

## 문항 · 유형 수정

`js/content.js` 상단 주석을 참고하세요.

- 각 선택지의 `pole` 글자(F/I, P/C, M/S)가 유형을 정합니다. 백엔드는 글자만 세기 때문에 **문구나 순서를 바꿔도 백엔드는 고칠 필요가 없어요.**
- 축마다 문항 수를 **홀수**로 유지하면 동점이 생기지 않아요. (현재 5·5·5)

| 코드 | 축 조합 | 유형 이름 |
|---|---|---|
| FPM | 현장 + 정치 + 대중 | 현장의 지지자 |
| IPM | 제도 + 정치 + 대중 | 탐구하는 정책 기획자 |
| FCM | 현장 + 문화·미디어 + 대중 | 개혁하는 문화인 |
| ICS | 제도 + 문화·미디어 + 당사자 | 공동체의 파수꾼 |
| FCS | 현장 + 문화·미디어 + 당사자 | 소통하는 확성기 |
| IPS | 제도 + 정치 + 당사자 | 법제화의 이끔이 |
| FPS | 현장 + 정치 + 당사자 | 열정적인 마이크 |
| ICM | 제도 + 문화·미디어 + 대중 | 내일을 보는 기록자 |

## 쿠키 · 개인정보

- 이름·연락처는 받지 않습니다. 닉네임(실명 쓰지 말라고 안내), 한마디, 응답, 유형만 저장됩니다.
- 내 결과는 `bqa_typetest_me` 쿠키(1년)에 저장되어 다시 들어오면 해설지를 볼 수 있어요.
- 해설지 하단 **내 기록 지우기**로 본인 기록을 서버에서 삭제할 수 있어요.

## 영수증 출력 (운영용 `admin.html`)

1. 처음 한 번: 연결 설정에 API 주소와 `ADMIN_TOKEN`을 넣고 저장 (그 컴퓨터 브라우저에만 저장)
2. 참여자가 말한 결과 번호 입력 → 미리보기
3. **인쇄**: 프린터 드라이버로 바로 출력 (용지 58mm / 80mm 선택, 인쇄 후 자동으로 '출력 완료' 표시)
4. **PNG 저장** / **텍스트 저장**: 프린터 전용 앱으로 보낼 때 사용
5. 부적절한 한마디는 목록에서 **숨기기** → 행진 · 통계 · 공유 링크에서 빠집니다

> 영수증 프린터와 직접 연결(ESC/POS, 블루투스 등)은 기기가 정해지면 추가할 예정입니다.
> `js/receipt.js`의 `renderReceiptText()`가 프린터용 텍스트를 이미 만들어 두었어요.

## 캐시 (업데이트가 바로 보이게 하기)

클라우드플레어가 JS·CSS·이미지에 브라우저 캐시 4시간을 붙이기 때문에,
`index.html`·`admin.html`은 `<script src>` 대신 **캐시 우회 로더**로 파일을 불러옵니다.
매번 서버에 변경 여부만 확인하므로(대부분 304 응답) 참여자가 강력 새로고침을 할 필요가 없어요.

- JS/CSS 파일을 새로 추가하면 HTML 맨 아래 로더의 파일 목록에도 넣어 주세요.
- 캐릭터 그림을 같은 파일명으로 바꾸면 늦어도 1시간 안에 반영돼요.
- 올린 직후에는 GitHub Pages·클라우드플레어 서버 쪽 캐시 때문에 최대 10분쯤 걸릴 수 있어요.
  급하면 클라우드플레어 **Caching → Configuration → Purge Everything**.

## 라벨 출력 (Niimbot B1, `label.html`)

참여 번호 → 라벨 2장(앞면 1/2 · 뒷면 2/2) 미리보기 → 블루투스로 바로 출력합니다.

- **맥북 Chrome**에서 `https://typetest.busanqueeract.kr/label.html` 열기 (Safari·Firefox는 Web Bluetooth 없음)
- 서버 연결 설정은 영수증 화면(`admin.html`)과 같아요 (API 주소 + `ADMIN_TOKEN`)
- **프린터 연결** → 기기 선택 창에서 B1 선택 (한 번 연결하면 유지, 끊기면 출력 버튼이 다시 연결)
- **출력**: 뒷면(2/2) → 앞면(1/2) 순서로 연속 출력, 성공하면 '출력 완료' 표시
- 예비용 **PNG 다운로드**(앞·뒤 각각) → 공식 NIIMBOT 맥 앱으로 출력
- 출력 설정: 앞면 QR 넣기/빼기, 농도 1~5, 세로 위치 보정(px)

라벨 구성

- 384×720px(203dpi, 8px/mm), 순수 흑백. 글자는 Pretendard(최소 22px ≈ 8pt), 선 두께 2px 이상
- 캐릭터는 `assets/characters`의 그림을 흑백 디더링 → **그림 파일만 바꾸면 라벨에도 반영**
- 문구는 `js/content.js`의 유형 데이터를 그대로 사용 (`meta.event`가 뒷면 하단 문구)
- 영수증 해설지(admin.html)와 같은 구성. 앞면: 단체·제목 / 닉네임 / 캐릭터 / 유형 이름 / 한 줄 설명 / #키워드 / 하단 QR. QR을 끄면 캐릭터가 커져요.
- 뒷면: 축 막대 3줄 / ■ 유형 소개 / 나의 강점 / 조심할 점 / 이런 활동이 잘 맞아요 / 네 가지 역할 / 찰떡 궁합 / 부딪히며 성장 / 한마디 상자 / 응원 문구.
  넘치면 글자 크기 → 말줄임 → 덜 중요한 것(소개 본문 → 부딪히며 성장 → 네 가지 역할 → 응원 → 궁합 설명 → 세 번째 활동 → 조심할 점) 순서로 빼서 맞춤.

코드: `label.html`, `js/label.js`(화면·출력), `js/label-render.js`(라벨 그리기),
`vendor/niimbot.js`(niimbot-web-bluetooth 2.6.0), `vendor/qrcode.js`(qrcode-generator 1.4.4)

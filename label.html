출력 설정
현장 운영 메모
  • 롤을 새로 넣을 때마다 전원 버튼을 한 번 누르세요. B1은 세로 80mm 이상 라벨을 처음 넣으면 첫 장이 자동 정렬되지 않아요. 전원 버튼을 누르거나 한 장 배출하면 정렬돼요.
  • 출력 순서는 뒷면(2/2) → 앞면(1/2)이에요.
  • 양면 카드 만들기: 뒷면 라벨은 받침지째로 둘레를 자르고, 앞면 라벨을 떼서 뒷면의 받침지 뒤쪽에 붙여요.
  • 기기 선택 창을 닫으면 나오는 User cancelled the requestDevice() chooser는 정상 메시지예요.
  • 연속 출력은 배터리 소모가 커요. 보조배터리 + USB-C 케이블을 연결해 두세요.
  • 블루투스가 계속 안 되면: 앞·뒤 PNG 다운로드 → 공식 NIIMBOT 맥 앱으로 출력.
